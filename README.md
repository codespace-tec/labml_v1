# LabML — laboratório web de aprendizado de máquina com tutor de IA socrático

Material público de apoio ao projeto **LabML**, um protótipo funcional que permite experimentar algoritmos de aprendizado de máquina no navegador, com um tutor de IA que conduz o aluno por perguntas em vez de entregar respostas. Foi desenvolvido como trabalho final de uma disciplina de especialização.

> **É um protótipo educacional.** Foi avaliado apenas quanto ao funcionamento técnico. Não houve estudo com estudantes.
